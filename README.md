## 🌐 Live Website

🔗 **https://hruthwik.vercel.app/**

An immersive 3D developer portfolio showcasing interactive WebGL animations, floating technology spheres, smooth UI transitions, and a production-ready deployment pipeline.

---

## ✨ Key Features

- 🎯 Interactive 3D Hero Section  
- 🌀 Floating & draggable 3D technology spheres  
- 🌌 Animated starfield background  
- 🧑‍💻 Professional vertical work experience timeline  
- 📬 Functional contact form powered by EmailJS  
- ⚡ Smooth animations using Framer Motion  
- 📱 Fully responsive across devices  
- 🚀 Automated CI/CD deployment via Vercel
